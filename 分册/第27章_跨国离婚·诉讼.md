跨国离婚最复杂的不是离婚本身，而是「哪国法院有管辖权」「判了对方认不认」「财产和子女怎么执行」。一章把管辖、判决承认、财产分割、子女抚养、以及离婚中最易踩坑的时点问题讲清，并给出中国法上的具体条文依据。

### 27.1 先定管辖：在哪国起诉才有效
<!-- 标签: 钱=少 时间=多 毅力=些 收益=高 口径=法律 影响=个人 -->
- 成本：几小时检索 + 一次当地律师咨询（数百至数千美元）。
- 说人话：跨国离婚的管辖通常看三件事——婚姻缔结地、被告的住所/居留地、财产所在地。多数国家允许「一方住所地」或「婚姻缔结地」法院起诉；中国《民事诉讼法》对涉外离婚有专门规定（被告住所地或经常居住地法院；被告在境外，可向原告住所地法院起诉）。起诉前先确认法院与被告联系送达方式，否则可能「判了也送不到」。
- 收益：选错法院 = 判决无法执行、或被驳回后重新起诉（多花数月与律师费）。管辖是整个跨国离婚的地基，先花几百美元做管辖核实，通常能省掉后面几千到几万美元的返工。
- 证据等级：B
- 来源：中国涉外离婚管辖见《民事诉讼法》相关条款（原告/被告住所地原则）https://www.court.gov.cn/ ；欧盟家事案件管辖见司法协作页 https://e-justice.europa.eu/ ; 美国州际与国际家事管辖见各州家事法与相关联邦规则 https://www.uscourts.gov/

### 27.2 外国离婚判决在中国：承认与执行的路径
<!-- 标签: 钱=少 时间=多 毅力=些 收益=高 口径=法律 影响=个人 -->
- 成本：涉外公证书 + 中文译文 + （可能的）附加证明书；诉讼费按财产/案件额计。
- 说人话：外国法院离婚判决要在中国被认可/执行，需向有管辖权的中级人民法院申请承认和执行。依据是《民事诉讼法》§281、§282：依两国缔结/参加的国际条约，或按互惠原则审查；认为不违反我国法律基本原则或国家主权、安全、社会公共利益的，裁定承认其效力，需执行的发出执行令。实操要点：判决书正本 + 经证明无误的中文译本 + 生效证明 +（被告在中国）合法送达证明 +（原告在中国）已合法传唤被告的证明 + 原婚姻登记证明。
- 收益：这条决定了「外国判了，中国认不认」。中国已与约 38 国签有双边条约，但与主要西方国家多无互惠条约，实际多走互惠原则；准备材料不全会被驳回，材料齐了通常能承认。不提前做这份功课，判决可能只是一张纸。
- 证据等级：A
- 来源：《民事诉讼法》第二百八十一条、第二百八十二条（外国法院判决的承认与执行）https://www.court.gov.cn/ ；司法协助与条约信息见中国法院网 https://www.court.gov.cn/ ；CMS 专家指南（中国承认与执行外国判决）https://cms.law/en/int/expert-guides/cms-expert-guide-to-recognition-and-enforcement-of-judgements/china

### 27.3 涉外文书免认证：海牙《取消外国公文书认证要求公约》与附加证明书
<!-- 标签: 钱=少 时间=少 毅力=少 收益=中 口径=程序 影响=个人 -->
- 成本：比传统双认证省时省费，通常数百元级别。
- 说人话：中国已于 2023-03-08 加入海牙《取消外国公文书认证要求的公约》（Apostille 公约），2023-11-07 对中国生效。中国与缔约国之间的公文书流转，不再走「外交部认证 + 使领馆认证」的双认证，改为出具「附加证明书（Apostille）」。中国大陆与港澳台之间、以及部分不适用情形（如与印度之间、与中国香港/澳门/台湾地区另行安排）有例外。
- 收益：离婚、继承、留学、学历、出生证明这类文书办理时间平均减少约 90%，成本大幅下降。对跨国离婚而言，出生证明、结婚证、未婚/离婚证明、学历公证都要用附加证明书，办错或漏办会直接卡住承认程序。
- 证据等级：A
- 来源：《取消外国公文书认证要求的公约》及附加证明书说明见中国领事服务网 https://cs.mfa.gov.cn/ ；附加证明书形式要求（Apostille Convention）见 HCCH https://www.hcch.net/ ; 附加证明书真伪核验 https://consular.mfa.gov.cn/VERIFY/；中国公证协会涉外公证要求见中国公证协会 http://www.chinanotary.org.cn/

### 27.4 离婚财产分割：婚前财产、婚后共同财产与跨境资产
<!-- 标签: 钱=少 时间=多 毅力=些 收益=高 口径=财产 影响=个人 -->
- 成本：资产梳理 + 一次专业法律/税务咨询。
- 说人话：跨国离婚最难啃的是资产。三个要点：① 婚前财产一般各自所有（各地法域差异大）；② 婚后所得多为共同财产，但「共同财产制 vs 分开财产制」因法域与协议而异；③ 跨境资产（境外房产、境外公司股权、境外账户、外币存款）能否纳入分割、适用哪国法、如何强制执行，都取决于资产所在地与相关法域的冲突规则。务必在离婚谈判早期就做一份「境内外资产清单」。
- 收益：漏掉的财产分文拿不到。境外资产如果未在离婚协议中明确披露/分割，另一方事后很难主张，形成「离婚了但对方仍占着大额资产」的局面。清单 + 估值 + 权属证明三件套，是谈判桌上最硬的筹码。
- 证据等级：B
- 来源：涉外离婚财产分割与冲突法通识；各法域财产制与分割原则见各国家事法；欧盟家事财产判决制度见 e-Justice https://e-justice.europa.eu/ ; 中国婚姻家庭财产制见《民法典》婚姻家庭编 https://www.gov.cn/

### 27.5 子女抚养权与探视：跨境怎么落地
<!-- 标签: 钱=少 时间=多 毅力=些 收益=高 口径=家庭 影响=子女 -->
- 成本：法律咨询 + 跨境执行程序（可能数月）。
- 说人话：涉及子女抚养权，核心是「小孩在哪国长期生活 + 抚养方能力 + 对方探视权」。跨国案里最常见的问题是：一方取得抚养权后回国执行，另一方在当地无法见到孩子；或探视安排在执行地被架空。关键动作是把抚养与探视安排做成「可执行的」条款：明确交接时间地点、往返费用承担、探视通知与联系方式、违约后果。
- 收益：抚养权判决拿得到 ≠ 真能见到孩子。跨境探视的执行高度依赖条款的可操作性和双方配合；写得含糊（只写「给予探视权」）在执行时几乎无法落地。可执行条款 + 明确的违约后果，是唯一能降低「赢了官司见不到孩子」风险的办法。
- 证据等级：B
- 来源：子女抚养与跨境探视实务通识；海牙《子女国际返还公约》（1980）关于跨境返还，见 HCCH https://www.hcch.net/ ; 中国《民法典》婚姻家庭编关于抚养与探望 https://www.gov.cn/ ; 美国子女返还法（ICPC）见 NCICPC https://www.ncicpc.org/

### 27.6 离婚冷静期与分居：容易踩的时点
<!-- 标签: 钱=少 时间=少 毅力=0 收益=中 口径=程序 影响=个人 -->
- 成本：零（只是知道时间点）。
- 说人话：许多法域对协议离婚/登记离婚设有冷静期或分居期（如中国大陆协议离婚有 30 日冷静期 + 30 日申请期），诉讼离婚则通常不设，但对某些情形（如有家庭暴力、有子女）有特殊程序要求。跨国案还要注意「居住地要求」：很多国家要求申请离婚时已在当地居住满一定期限（如 1–2 年），不满足不能申请。
- 收益：忽略时点会导致「已起诉才发现不符合管辖/居住前提」，白跑一趟；忽略冷静期则可能在冷静期内反悔、又回到起点。出发前把目的地的离婚程序要件（居住年限、冷静期、是否需分居）列一张表，是最低成本的保险。
- 证据等级：C
- 来源：离婚程序与冷静期通识；示例：中国离婚登记程序与冷静期规定见中国政府网 https://www.gov.cn/ ；欧盟各国离婚程序见 e-Justice https://e-justice.europa.eu/

### 27.7 跨国诉讼的费用保全与律师费
<!-- 标签: 钱=多 时间=多 毅力=些 收益=中 口径=金钱 影响=个人 -->
- 成本：律师费按阶段数千至数万美元；财产保全费按标的额。
- 说人话：跨境民商事诉讼成本高、周期长。实操要点：① 先做财产线索调查（在对方所在法域查财产登记、账户、房产），因为胜诉不等于拿得到钱；② 必要时申请诉前/诉中财产保全（但需担保）；③ 多数英美法域诉讼遵循「败诉方付律师费」（American rule 相反），跨境案件务必先确认费用规则，否则赢官司却赔掉律师费。
- 收益：财产保全 + 费用规则这两项，常常比「官司能不能赢」更决定最终是否划算。跨境案件里「赢了但拿不到钱」「赢了但倒贴律师费」都不少见，先算清成本再决定是否起诉。
- 证据等级：B
- 来源：英美诉讼费用规则（败诉方付/各付各的）见美国法院规则与 ADR 资料 https://www.uscourts.gov/ 与英国 Civil Procedure Rules https://www.justice.gov.uk/ ; 财产保全通识见各国民事诉讼法；中国诉前保全见《民事诉讼法》 https://www.court.gov.cn/

### 27.8 涉外婚姻的「身份文件」：结婚证/离婚证如何跨境使用
<!-- 标签: 钱=少 时间=少 毅力=少 收益=中 口径=程序 影响=个人 -->
- 成本：公证 + 附加证明书 + 翻译，数百至数千元。
- 说人话：跨国离婚里最容易卡在「证件」而不是「法条」：结婚证在中国领的，去国外要用需公证 + 附加证明书 + 当地承认翻译；反过来境外领的结婚/离婚证回中国用，同样需要相应手续与译本。办之前先确认目标国家对该类文件是否有额外要求（如有效期、必须附译本、公证要求）。
- 收益：证件不合规是跨境离婚「申请被退回」的高频原因。先把证件链理顺（结婚证、护照、户籍/无配偶证明、涉外文书附加证明书），能避免反复补件拖延数月。
- 证据等级：B
- 来源：涉外文书办理与附加证明书见中国领事服务网 https://cs.mfa.gov.cn/ ; 公证要求见中国公证协会 http://www.chinanotary.org.cn/ ; 无配偶（单身）证明等文件标准格式见各地公证处指引；附加证明书核验 https://consular.mfa.gov.cn/VERIFY/

### 27.9 离婚中的境外资产隐匿与法律工具
<!-- 标签: 钱=少 时间=中 毅力=些 收益=中 口径=风险 影响=个人 -->
- 成本：律师调查与取证数百至数千美元。
- 说人话：离婚中对方常会转移、隐匿共同财产。常见反制工具：财产线索/调查取证、诉前或诉中财产保全、撤销隐匿财产的分割决定（多数法域对「恶意转移共同财产」有少分/不分规则）、对跨境转移申请资金冻结令。要点是「发现即行动」，等离婚判完再去追讨往往追不回。
- 收益：法律本身就设了「防隐匿」的牙齿（撤销权、少分/不分），但这些工具都有时限和程序要求。谈判阶段就固定证据并申请保全，比判决后追偿现实得多。
- 证据等级：C
- 来源：离婚财产隐匿与撤销权、财产保全实务通识；中国民法典婚姻家庭编相关规则 https://www.gov.cn/ ；英美法域家事法院对隐匿财产的救济见各家事法院指引 https://www.courts.gov/ 与 https://www.justice.gov.uk/

### 27.10 能不能「用离婚解决身份/税务问题」——红线在哪
<!-- 标签: 钱=少 时间=少 毅力=0 收益=高 口径=风险 影响=个人 -->
- 成本：零（认知成本）；踩线的代价可能是刑事指控。
- 说人话：以离婚为工具做资产重组、税务安排或身份转换，各国都有红线：① 虚假离婚（未实际分居、只为减税/换身份）在多国可构成欺诈甚至伪造文书；② 跨境税务居民身份的改变不因离婚自动改变，可能触发全球征税与退出税；③ 「离婚切割财产」若属虚构交易，可能被税务机关穿透并追税加罚。以离婚为「规划工具」前，务必拿到税务与法律双重意见。
- 收益：认清红线，避免把「聪明的筹划」变成「刑事风险」或「追税+罚款」。离婚是身份与法律关系的真实变更，不是可以随意编排的交易。
- 证据等级：A
- 来源：各国反虚假离婚与税务穿透规则；示例：美国IRS 关于离婚与申报义务 https://www.irs.gov/ ；中国《个人所得税法》与税收征管规则见中国政府网 https://www.gov.cn/ ；CRS 下的金融账户涉税信息自动交换见 OECD https://www.oecd.org/tax/exchange-of-tax-information/

### 27.11 涉外离婚与在境外的家暴/人身安全保护令
<!-- 标签: 钱=少 时间=少 毅力=些 收益=高 口径=安全 影响=个人 -->
- 成本：申请保护令一般零成本；律师费数百至数千美元。
- 说人话：跨国关系里出现家暴或人身威胁时，可向有管辖权的法院申请人身安全保护令/保护令（order of protection）。中国《反家庭暴力法》有「人身安全保护令」制度；英美法域有 restraining order / protective order。若担心对方在境外诉讼期间的反制风险，可考虑律师单方沟通、不透露住址等策略。
- 收益：保护令在很多法域可附带的救济很具体（禁止接触、迁离住所、禁止传播隐私信息、警方协助执行）。早申请比事后以普通侵权索赔有效得多；跨境执行虽难，但可作为对方所在国诉讼中的关键证据。
- 证据等级：B
- 来源：中国《反家庭暴力法》人身安全保护令见中国政府网 https://www.gov.cn/ ；美国 restraining order 见各州法院 https://www.courts.gov/ ; 英国 injunctions 见 HMCTS https://www.gov.uk/ ；联合国妇女署家暴支持资源 https://www.unwomen.org/

### 27.12 离婚后：税、社保、证件与跨境居留的连带影响
<!-- 标签: 钱=少 时间=中 毅力=些 收益=中 口径=金钱 影响=个人 -->
- 成本：数周梳理 + 少量申报/变更费用。
- 说人话：离婚不只是婚姻关系解除，还会连带动几件事：税务上（境外所得申报、税收居民身份、抚养费/赡养费税务处理、财产分割可能涉税）；社保上（部分国家离婚影响配偶/受抚养人医保或养老金资格）；证件上（居留身份、探视签证、子女抚养安排）；以及财产与债务的重新确认。离婚判决落地后，逐一处理这些「连带项」，否则可能留下一堆后续麻烦。
- 收益：把「判决书」翻译成「行动清单」，逐项打钩，是避免离婚后再生纠纷的唯一办法。漏掉的往往是税务申报和子女证件这两项——前者可能补税加罚，后者影响孩子出行与入学。
- 证据等级：C
- 来源：离婚后税务与申报通识；示例：中国个人所得税申报与专项附加扣除见中国政府网 https://www.gov.cn/ ；各国离婚税影响差异较大，需按所在国税务规定；跨境居留变更见各国移民局（示例 USCIS https://www.uscis.gov/ ）
- 备注：〔争议〕离婚对税务居民身份的具体影响各国差异极大且常需个案分析，不要套用通用结论。
