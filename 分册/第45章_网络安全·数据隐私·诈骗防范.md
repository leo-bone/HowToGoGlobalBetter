出海人群是跨国诈骗的高危目标：冒充使领馆、假求职租房、杀猪盘、加密货币骗局都盯准「人在外地、信息不对称」。这一章把骗局类型、防护工具、止损通道讲清，每条给权威举报入口。

### 45.1 海外常见诈骗类型：电诈/杀猪盘跨国化
<!-- 标签: 钱=0 时间=少 毅力=0 收益=高 口径=风险 影响=个人 -->
- 成本：认知成本；中招则倾家荡产。
- 说人话：瞄准华人的诈骗常用中文话术：冒充国内公安/使馆、假客服退款、杀猪盘投资恋爱、假换汇。话术再真，核心都是「诱导你转账/给验证码/下载屏幕共享软件」。
- 收益：记住「任何要你转账、给验证码、屏幕共享的，都是诈骗」这一条，能挡掉 90% 骗局；情绪越急越要停手核实。
- 证据等级：C
- 来源：反诈资源见各国机构（美国 FTC https://www.ftc.gov/ 、澳洲 Scamwatch https://www.scamwatch.gov.au/ ）

### 45.2 身份盗窃（identity theft）防护
<!-- 标签: 钱=少 时间=少 毅力=些 收益=高 口径=安全 影响=个人 -->
- 成本：监控与防护时间。
- 说人话：在海外，护照号、社保号（SSN）、税号一旦泄露，可被用来开账户、贷钱、报税。不随意给证件复印件、用遮挡、定期查信用报告（如美国 AnnualCreditReport）、开账户警报。
- 收益：身份泄露的善后成本是数千美元+数年；前置防护比事后解冻信用便宜得多。
- 证据等级：B
- 来源：美国 FTC 身份盗窃 https://www.identitytheft.gov/ ; 各国信用与反诈机构

### 45.3 电话/短信钓鱼与本地反诈
<!-- 标签: 钱=0 时间=少 毅力=0 收益=中 口径=安全 影响=个人 -->
- 成本：认知成本。
- 说人话：到新国家先把本地反诈热线存好（如英国 Action Fraud 0300 123 2040、澳洲 Scamwatch、美国 FTC）；陌生来电要验证码/银行信息的一律不信，挂断后从官方号码回拨核实。
- 收益：本地反诈渠道是「被骗后第一时间举报冻结」的钥匙；用国内习惯应对海外骗局会慢半拍。
- 证据等级：B
- 来源：英国 Action Fraud https://www.actionfraud.police.uk/ ; 澳洲 Scamwatch https://www.scamwatch.gov.au/ ; 美国 FTC https://www.ftc.gov/

### 45.4 公共 WiFi 与 VPN 合规
<!-- 标签: 钱=少 时间=少 毅力=些 收益=中 口径=安全 影响=个人 -->
- 成本：VPN 订阅费。
- 说人话：咖啡厅免费 WiFi 别登银行/邮箱，用手机热点或可信 VPN；注意部分国（如阿联酋、白俄）限制/禁止未授权 VPN，违规可能受罚。
- 收益：敏感操作走安全网络，避免账号被嗅探；同时别在禁用 VPN 的国硬用，触法更麻烦。
- 证据等级：B
- 来源：各国 VPN 法规见当地电信/安全部门；安全上网建议 https://www.ftc.gov/

### 45.5 银行账户与支付安全
<!-- 标签: 钱=少 时间=少 毅力=些 收益=高 口径=安全 影响=个人 -->
- 成本：防护习惯。
- 说人话：开账户用强密码+2FA、不共用设备、不点银行短信链接（自己进 App 查）、设交易提醒。大额转出前电话核实对方；不替陌生人代收代付（洗钱风险）。
- 收益：银行安全习惯零成本却挡住绝大多数盗刷与钓鱼；代收代付是洗钱「工具人」高发区。
- 证据等级：C
- 来源：银行安全见各国央行与银行反欺诈提示；FTC https://www.ftc.gov/

### 45.6 加密货币骗局
<!-- 标签: 钱=0 时间=少 毅力=0 收益=高 口径=风险 影响=个人 -->
- 成本：认知成本；中招则归零。
- 说人话：假交易所、假投资群、杀猪盘币、假空投，「稳赚不赔」「内幕币」都是红旗。只走持牌交易所、不把币转给「老师」、不信私聊荐币。
- 收益：加密骗局归零且跨境难追回；「高收益+紧迫感」出现即拉黑，是最省钱的法则。
- 证据等级：C
- 来源：FTC 加密投资骗局 https://www.ftc.gov/ ; 各国证券监管警示

### 45.7 投资骗局：高收益/庞氏
<!-- 标签: 钱=0 时间=少 毅力=0 收益=高 口径=风险 影响=个人 -->
- 成本：认知成本。
- 说人话：海外遇「保本高息、外汇盘、原始股、地产代持高返」要警惕，庞氏与资金盘专挑新移民。查对方是否在当地金融监管机构注册（如美国 SEC、英国 FCA、香港 SFC）。
- 收益：向监管机构核验牌照 1 分钟，能挡掉绝大多数非法投资；「注册地神秘、承诺保收益」基本是局。
- 证据等级：B
- 来源：美国 SEC 投资者警示 https://www.sec.gov/ ; 英国 FCA 警示 https://www.fca.org.uk/ ; 香港 SFC https://www.sfc.hk/

### 45.8 租房/求职诈骗：出海高频
<!-- 标签: 钱=0 时间=少 毅力=些 收益=高 口径=风险 影响=个人 -->
- 成本：认知成本。
- 说人话：出海前远程找房/找工作是诈骗重灾区：假房东收定金消失、假雇主收「签证费/培训费」、假中介收钱不办事。原则：未实地看房不付大额定金、雇主招你还要你先付钱必是骗局。
- 收益：这两类骗局专坑「还没落地」的人；坚持「见真人、签合同、走托管」三原则，能避开。
- 证据等级：C
- 来源：美国 FTC 求职诈骗 https://www.ftc.gov/news-events/topics/consumer-protection/job-scams ; 英国 Action Fraud https://www.actionfraud.police.uk/ ; 澳洲 Scamwatch https://www.scamwatch.gov.au/

### 45.9 社交工程与冒充使领馆
<!-- 标签: 钱=0 时间=少 毅力=0 收益=高 口径=风险 影响=个人 -->
- 成本：认知成本。
- 说人话：诈骗常冒充中国使领馆、当地警方、快递公司，称「你有包裹/证件异常/涉案」，诱导转账或透露信息。使领馆不会电话要你转账或要银行信息，遇此直接挂断并联系官方核实。
- 收益：使领馆「要钱要验证码」必假，这一条能挡掉针对华人最高频的冒充骗局。
- 证据等级：C
- 来源：中国领事保护反诈提示 https://cs.mfa.gov.cn/ ; 各国使领馆官方联络见外交部网站

### 45.10 数据隐私设置（社交平台）
<!-- 标签: 钱=0 时间=少 毅力=些 收益=中 口径=安全 影响=个人 -->
- 成本：设置时间。
- 说人话：把社交账号设为私密、关闭地理标签、不晒护照/机票/住址细节；诈骗者靠这些拼出你的行踪与身份。定期清理授权第三方 App。
- 收益：少晒隐私 = 少被定向诈骗；海外生活「低调」是低成本安全防护。
- 证据等级：C
- 来源：隐私设置建议见各国数据保护机构（如英国 ICO https://ico.org.uk/ 、欧盟 EDPS）

### 45.11 设备与密码安全：2FA/密码管理器
<!-- 标签: 钱=少 时间=少 毅力=些 收益=高 口径=安全 影响=个人 -->
- 成本：管理器订阅费（多免费）。
- 说人话：每个账户独立强密码 + 密码管理器（Bitwarden/1Password）+ 2FA（Authenticator 而非短信）；系统及时更新。这是防账号被盗的底层防线。
- 收益：密码管理器+2FA 是零成本的高杠杆防护；「一个密码走天下」一旦泄露全盘崩。
- 证据等级：C
- 来源：网络安全基础见 CISA https://www.cisa.gov/ ; FTC https://www.ftc.gov/

### 45.12 被诈骗后的止损：冻结/报案/领事
<!-- 标签: 钱=少 时间=少 毅力=多 收益=高 口径=风险 影响=个人 -->
- 成本：止损动作要快。
- 说人话：一旦转错账/被骗：① 立刻联系银行尝试止付；② 向当地警局报案拿报案号；③ 联系中国使领馆与国内反诈（96110）请求协作；④ 保留所有聊天/转账记录。跨境追回极难，争的是「前 1 小时」。
- 收益：黄金 1 小时止损比事后追讨有效百倍；保留证据是跨国协作的唯一凭仗。
- 证据等级：C
- 来源：中国反诈 96110 与领事保护 https://cs.mfa.gov.cn/ ; 当地警局与反诈机构

### 45.13 儿童网络保护
<!-- 标签: 钱=少 时间=少 毅力=些 收益=中 口径=安全 影响=子女 -->
- 成本：家长监管时间。
- 说人话：出海孩子更早独立用网，需设家长控制、讲解网恋/裸聊勒索/陌生人诱骗。性勒索（sextortion）对青少年高发，遇威胁立即断联并求助。
- 收益：提前给孩子「网络边界」教育，避免裸聊勒索等跨境难办的案件；沉默的孩子最易被缠。
- 证据等级：C
- 来源：儿童网络保护见各国儿童保护机构（如 NCMEC https://www.missingkids.org/ 、英国 https://www.ceop.police.uk/ ）

### 45.14 各国反诈机构与举报渠道
<!-- 标签: 钱=0 时间=少 毅力=0 收益=中 口径=工具 影响=个人 -->
- 成本：认知成本。
- 说人话：把所在国的反诈举报入口存好：美国 FTC/IC3、英国 Action Fraud、澳洲 Scamwatch、加拿大 Anti-Fraud Centre；中国的 96110 与 12339（国安）。被骗第一时间就地举报。
- 收益：举报渠道是「止损+留证+协作」的起点；临时搜反而慢，提前存好最稳。
- 证据等级：B
- 来源：FTC https://www.ftc.gov/ ; IC3 https://www.ic3.gov/ ; Action Fraud https://www.actionfraud.police.uk/ ; Scamwatch https://www.scamwatch.gov.au/
