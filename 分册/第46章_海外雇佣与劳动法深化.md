雇佣是出海企业与个人的高频雷区：解雇保护强弱天差地别、社保是雇主硬责任、签证绑雇主让人不敢跳槽、跨境远程发薪涉及合规。本章深化第 4 章，把雇佣全链条的硬约束讲清。

### 46.1 雇佣合同必备条款（各国差异）
<!-- 标签: 钱=少 时间=中 毅力=些 收益=高 口径=合规 影响=个人/企业 -->
- 成本：合同审阅时间。
- 说人话：正规雇佣合同应含：岗位/地点/薪资/工时/假期/试用期/解雇通知期/保密与知识产权归属。大陆法系（德法）强制条款多，英美更靠约定。签前逐项核对，别只看薪资。
- 收益：合同是雇佣关系的地基；忽略通知期与 IP 归属，离职或创业时吃暗亏。
- 证据等级：B
- 来源：ILO 雇佣合同原则 https://www.ilo.org/ ; 各国劳动法（如英国 ACAS https://www.acas.org.uk/ ）

### 46.2 试用期与解雇保护：at-will vs 强保护
<!-- 标签: 钱=少 时间=少 毅力=0 收益=高 口径=法律 影响=个人/企业 -->
- 成本：认知成本。
- 说人话：美国多州是「at-will」（原则上可随时解雇，反歧视等例外）；德/法/中等大陆法要求「正当理由 + 通知期 + 有时需劳工局/工会同意」。雇主乱开人可能被诉非法解雇并赔钱。
- 收益：搞清所在地解雇规则，雇员知边界、雇主避违法；在强保护国，「想开就开」是错觉。
- 证据等级：A
- 来源：ILO 解雇保护公约 https://www.ilo.org/ ; 美国 DOL https://www.dol.gov/ ; 英国 ACAS https://www.acas.org.uk/

### 46.3 最低工资与工时：EU/US/UK 差异
<!-- 标签: 钱=少 时间=少 毅力=0 收益=中 口径=法律 影响=个人 -->
- 成本：认知成本。
- 说人话：欧盟多国法定最低时薪+每周 40 小时左右上限+加班溢价；美国联邦最低工资低、加班按 FLSA 算 1.5 倍但豁免多；英国有 NLW 与 48 小时周上限（可书面放弃）。雇主低于法定即违法。
- 收益：雇员核对当地最低薪与加班规则，避免被低薪长工时剥削；雇主合规是硬底线。
- 证据等级：B
- 来源：美国 DOL FLSA https://www.dol.gov/ ; 英国 GOV.UK 最低工资 https://www.gov.uk/minimum-wage ; 欧盟就业 https://employment-social-affairs.ec.europa.eu/

### 46.4 带薪假与病假：法定最低
<!-- 标签: 钱=少 时间=少 毅力=0 收益=中 口径=法律 影响=个人 -->
- 成本：认知成本。
- 说人话：多数发达国强制带薪年假（欧盟通常 ≥20 天、部分国更多）、带薪病假、育儿假。美国联邦层面无统一带薪病假/年假强制（州法补），是主要差异点。
- 收益：在美工作别默认有法定带薪假；在欧工作记得用完法定假，是法定权利不是施舍。
- 证据等级：B
- 来源：欧盟带薪假指令 https://employment-social-affairs.ec.europa.eu/ ; 美国 DOL https://www.dol.gov/

### 46.5 社保与个税代扣：雇主责任
<!-- 标签: 钱=少 时间=中 毅力=些 收益=高 口径=合规 影响=企业 -->
- 成本：合规系统搭建。
- 说人话：雇主须从工资代扣个税与社保（养老/医疗/失业），并承担雇主匹配部分，按月申报缴纳。漏缴会被罚且损害雇员权益；跨境雇人需确认当地社保登记义务。
- 收益：社保合规是雇佣的硬成本也是硬责任；雇员查工资单「代扣项」能验证雇主是否依法。
- 证据等级：B
- 来源：各国社保税局（美国 IRS https://www.irs.gov/ 、英国 HMRC https://www.gov.uk/government/organisations/hm-revenue-customs ）

### 46.6 非竞争与保密条款效力
<!-- 标签: 钱=少 时间=中 毅力=些 收益=中 口径=法律 影响=个人 -->
- 成本：审阅时间。
- 说人话：竞业限制（non-compete）在美多数州可 enforce（加州禁止）、在欧受严格限制（需合理范围+补偿）；保密与 IP 归属普遍有效。签前评估「条款是否在该国可执行」，别被一纸禁业吓住或轻视。
- 收益：了解所在地对竞业的态度，雇员离职规划更清晰；雇主条款写太宽反而无效。
- 证据等级：B
- 来源：美国 FTC 竞业规则 https://www.ftc.gov/ ; 加州 Business & Professions Code §16600 ; 欧盟竞业限制判例

### 46.7 远程雇佣与雇主实体（EOR）
<!-- 标签: 钱=中 时间=中 毅力=些 收益=高 口径=合规 影响=企业 -->
- 成本：EOR 服务费每人每月数百美元。
- 说人话：想在海外雇人但没当地实体，可用 EOR（雇主记录代理）合规发薪、缴税、管社保，你只管业务。避免「直接签独立合同假装无雇佣关系」被认定为隐蔽雇佣（misclassification）。
- 收益：EOR 让小团队合规出海雇人，比硬开子公司便宜；把人当合同工却实际管理，被查要补税罚款。
- 证据等级：B
- 来源：用工分类合规见各国劳工部门（美国 DOL https://www.dol.gov/ 、英国 HMRC ）；EOR 模式见行业服务商

### 46.8 实习/合同工 vs 正式员工
<!-- 标签: 钱=少 时间=少 毅力=些 收益=中 口径=合规 影响=个人/企业 -->
- 成本：认知成本。
- 说人话：合同工（contractor）不享员工福利与解雇保护，但灵活；若实际受管理、用公司系统、长期专属，可能被重定为员工（employee），触发补社保与福利。分类看「实质」非标签。
- 收益：双方都按实质关系定分类，避免「挂合同工享员工待遇」的错位与稽查风险。
- 证据等级：B
- 来源：美国 IRS 用工分类 https://www.irs.gov/ ; 英国 HMRC IR35 规则 https://www.gov.uk/ir35

### 46.9 歧视与职场骚扰：法律救济
<!-- 标签: 钱=少 时间=中 毅力=些 收益=中 口径=法律 影响=个人 -->
- 成本：投诉与可能的法律费。
- 说人话：多数国禁止基于种族/性别/宗教/年龄/残障的歧视与性骚扰，设有平等就业委员会类机构受理。留存证据（邮件、证人）是投诉前提。
- 收益：了解救济渠道，被侵权时知去哪告；沉默助长施害者，证据是底气。
- 证据等级：B
- 来源：美国 EEOC https://www.eeoc.gov/ ; 英国 EHRC https://www.equalityhumanrights.com/ ; ILO 反歧视 https://www.ilo.org/

### 46.10 工伤与职业安全（深化第 26.4）
<!-- 标签: 钱=少 时间=中 毅力=些 收益=高 口径=健康 影响=个人 -->
- 成本：申报时间。
- 说人话：雇主须提供安全环境并投工伤保险；雇员受伤立即报工伤、留医疗与事故记录。英美澳有独立工伤赔偿体系，部分情况雇主难免责（见 26.4）。
- 收益：及时报工伤锁定赔偿资格；拖延或私了常丢权益。
- 证据等级：B
- 来源：英国 HSE https://www.hse.gov.uk/ ; 美国 OSHA https://www.osha.gov/ ; 国际劳工组织 https://www.ilo.org/

### 46.11 遣散费与离职补偿
<!-- 标签: 钱=少 时间=少 毅力=0 收益=中 口径=法律 影响=个人 -->
- 成本：认知成本。
- 说人话：强保护国（德、法、中等）裁员需通知期+遣散费（常按工龄）；美国 at-will 无强制遣散但大规模裁员有 WARN 通知要求。合同里的通知期优先于法定。
- 收益：离职前算清应得通知期与补偿，避免被「请你走」时少给；签字放弃权利前先核法定下限。
- 证据等级：B
- 来源：ILO 终止雇佣 https://www.ilo.org/ ; 美国 WARN Act https://www.dol.gov/ ; 各国劳动法

### 46.12 工会与集体谈判
<!-- 标签: 钱=少 时间=少 毅力=些 收益=中 口径=法律 影响=个人/企业 -->
- 成本：认知成本。
- 说人话：欧洲与部分国家工会力量强，工资/条件常由集体协议定，个人合同不得低于协议。雇主在裁员/重大变更时常需与工会协商。
- 收益：在工会强地工作，了解 collective agreement 能知道你的真实权利；企业则需把协商成本纳入计划。
- 证据等级：B
- 来源：ILO 结社自由与集体谈判 https://www.ilo.org/ ; 欧盟社会对话 https://employment-social-affairs.ec.europa.eu/

### 46.13 跨境远程为母国公司打工的合规
<!-- 标签: 钱=少 时间=中 毅力=些 收益=高 口径=合规 影响=企业 -->
- 成本：合规审查。
- 说人话：你人在 A 国、为 B 国公司远程打工，A 国可能认定你在当地构成雇佣关系（即使合同写 contractor），要求当地税/社保/签证匹配。别以为「远程就不用管当地法」。
- 收益：跨境远程的合规归属极常被忽略；用 EOR（46.7）或明确自雇+合法签证，比「假装不存在」稳。
- 证据等级：B
- 来源：各国远程雇佣税务与签证见税务与移民局；OECD 远程工作研究 https://www.oecd.org/migration/

### 46.14 签证绑定雇主的风险
<!-- 标签: 钱=0 时间=少 毅力=0 收益=高 口径=风险 影响=个人 -->
- 成本：认知成本。
- 说人话：H1B、英国 Skilled Worker、新加坡 EP 等工签都「绑雇主」，换工作需新雇主重新担保，失业有宽限期（如美国 60 天）否则须离境。这限制了跳槽议价力。
- 收益：绑雇主签下，留足「找下家」的缓冲，别在签证快到期才慌；议价时把签证风险算进离职成本。
- 证据等级：A
- 来源：美国 USCIS H1B 转换 https://www.uscis.gov/ ; 英国 Skilled Worker https://www.gov.uk/skilled-worker-visa

### 46.15 工资支付与外汇：跨境发薪
<!-- 标签: 钱=少 时间=中 毅力=些 收益=中 口径=合规 影响=企业 -->
- 成本：发薪与换汇成本。
- 说人话：跨境发薪要合规扣税、用可核渠道、注意外汇管制（如中国个人收汇申报）。用全球薪酬服务商（如 Deel、Remote）可自动化多国合规发薪。
- 收益：合规发薪避免雇员被外管拦截、企业被稽查；私下换汇发薪两头不合规。
- 证据等级：B
- 来源：OECD 跨境远程工作与税务 https://www.oecd.org/migration/ ; 美国 IRS 雇主税务 https://www.irs.gov/ ; 英国 HMRC https://www.gov.uk/government/organisations/hm-revenue-customs

### 46.16 劳动监察与投诉渠道
<!-- 标签: 钱=0 时间=少 毅力=些 收益=高 口径=工具 影响=个人 -->
- 成本：认知成本。
- 说人话：权益受损先内部 HR/工会，不行再找当地劳动监察/平等机构（美国 EEOC/DOL、英国 ACAS、欧盟 EURES/劳工检察）。保留证据链是投诉胜算的关键。
- 收益：知道官方投诉入口，被侵权时有路可走；忍气吞声只会让违规雇主更肆无忌惮。
- 证据等级：B
- 来源：美国 DOL https://www.dol.gov/ ; 英国 ACAS https://www.acas.org.uk/ ; 欧盟 EURES https://eures.ec.europa.eu/
