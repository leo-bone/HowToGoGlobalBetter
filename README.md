# 高性价比出海指南

> 用最少的费用、税收、时间、精力与合规风险，换回最多的真实机会、净收益、身份选项与避开归零。

一份**循证出海手册**，覆盖企业出海、求职、留学、创业、婚恋、旅行，以及税收、雇佣、地缘政治、文化、宗教等所有真正会踩坑的维度。每条建议都标注 **成本 / 说人话 / 收益 / 证据等级（A·B·C）/ 来源 / 备注**。

## 怎么用

- **从总入口进**：浏览器打开 `入口.html`，四个视图（离线检索／速查卡／正文／README）一处汇总，并附「我该用哪个？」场景对照表。
- **读正文**：`高性价比出海指南.md`（全部 273 条，按章展开）
- **离线检索**：用浏览器打开 `index.html`，可按**章 / 证据等级（A·B·C）/ 关键词**筛选全部条目，支持「只显示〔争议〕」与「随机一条」，无需联网。
- **分目的地速查卡**：打开 `速查卡.html`，按目的地（泰国 / 美国 / 新加坡 / 阿联酋 / 欧洲 / 马来 / 香港 / 日韩 / 澳新 / 英国 / 印尼越南）一键看相关条目。
- **直接上手工具**：打开 `工具箱.html`，用实体选择决策树、出海成本估算器、出海前核对清单、跨境合同模板库。

## 证据分级说明

- 〔A〕权威长期统计、官方监管文件、顶刊随机／追踪研究。
- 〔B〕单项高质量研究、权威机构（OECD／Vanguard／KPMG／PwC）报告、经典论文。
- 〔C〕合理推论／广泛共识，逻辑硬但不勉强挂精确出处。
