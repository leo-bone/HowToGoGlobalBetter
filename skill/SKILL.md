# 高性价比出海指南（AI Skill）

本 skill 是《高性价比出海指南》的结构化检索入口。手册正文 **56 章 634 条**，循证风格，每条标注 `成本 / 说人话 / 收益 / 证据等级(A·B·C) / 官方来源`。

核心主张：**「高性价比出海」= 把税、合规、身份代价、隐性风险一起算进总账后，风险调整后的净收益最高**，而不是「哪里税最低、哪里最便宜」。

## 何时使用
- 用户问「去哪国出海 / 求职 / 留学 / 创业 / 退休」「某个签证怎么走」「税怎么算」「跨境架构怎么搭」「某国生活风险」「数字游民怎么操作」等。
- 需要给出**可核验的官方来源**（而非泛泛而谈）时。
- 需要帮用户做「目的地 / 路径 / 架构」的取舍决策时。

## 使用流程
1. 按用户问题锁定 1–3 个相关章节（见下方章节地图）。
2. 用 `出海指南数据.json` 过滤出候选条目，或读 `分册/第NN章_*.md` 拿该章全文。
3. 回答时给出：**结论 → 成本 → 风险红线 → 证据等级 → 官方来源 URL**。
4. 涉及大额资产、身份变更、敏感行业（半导体/AI/无人机/电池/生物）时，明确提示「以官方最新发布为准，咨询持牌国际税务/移民律师」。
